## Features
- increment button (increases count by 1)
- Postive number coloured by Green
- decrement button (decreases count by 1)
- Negative number coloured by Red
- reset button (sets count back to 0)
- display/window showing the current count

> When the Program load the Counter should be 0
>
> When the user press the + button the counter should incremented by 1
>
> When the user press the - button the counter should decremented by 1
>
> When the user press reset button the counter should be equal 0
